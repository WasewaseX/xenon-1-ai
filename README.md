# زنون ۱ — پلتفرم هوش مصنوعی فارسی‌محور

**Xenon 1** یک پلتفرم هوش مصنوعی چندوجهی، عامل‌محور و فارسی‌اول است که روی موتور استنتاج GLM ساخته شده است: گفتگوی جریانی، استدلال عمیق، کدنویسی، پژوهش وب همراه با ارجاع، بینایی و OCR، تولید تصویر، گفتار به متن و متن به گفتار، حافظه پایدار با تأیید کاربر، و سازمان‌دهی کامل گفتگوها — همه در یک رابط راست‌به‌چپ زیبا.

> اصل طراحی: **شفافیت کامل**. زنون ۱ ادعای ساختگی درباره «مدل اختصاصی آموزش‌دیده» ندارد؛ مدل سروکننده (`glm-4-plus` از درگاه GLM) در نوار وضعیت و زیر هر پاسخ به‌صورت شفاف نمایش داده می‌شود و نقشه راه واقعی به‌سمت مدل‌های اختصاصی در همین سند آمده است.

## 🚫 محدودیت‌های صادقانه (باید بدانید)

1. **مدل سروکننده**: درگاه این محیط، درخواست‌های متنی را با `glm-4-plus` سرو می‌کند؛ انتخاب «پروفایل» رفتار (استدلال/جست‌وجو/بینایی) را تغییر می‌دهد، نه هویت مدل پایه را.
2. **تشخیص گفتار (ASR)**: مدل ASR درگاه فعلی برای فارسی (و حتی انگلیسی) خروجی چینی/نامعتبر می‌دهد. ورودی صوتی در UI به‌صورت شفاف این محدودیت را اعلام می‌کند. راه‌حل واقعی: اتصال Whisper محلی (فاز ۶ نقشه راه).
3. **زنجیره استدلال نمایشی**: حالت استدلال فعال است و پاسخ‌های گام‌به‌گام تولید می‌شود، اما درگاه `reasoning_content` خام را منتشر نمی‌کند؛ بنابراین بخش «زنجیره استدلال» فقط وقتی داده واقعی برسد نمایش داده می‌شود.
4. **فیلتر تصویرسازی**: درگاه تصویر متن فارسی را گاهی به‌اشتباه رد می‌کند؛ زنون به‌طور خودکار ترجمه انگلیسی انجام می‌دهد و در صورت نیاز دوباره با متن اصلی تلاش می‌کند.
5. **PDF/Word**: فعلاً پیوست‌های متنی، کد و تصویر پشتیبانی می‌شوند؛ استخراج PDF/Word در نقشه راه است (ادعای پشتیبانی ساختگی نداریم).

## 🏗 معماری

```
src/
├── app/
│   ├── layout.tsx              ← fa/RTL، فونت Vazirmatn، ThemeProvider
│   ├── page.tsx                ← ورودی رابط (XenonWorkspace)
│   └── api/
│       ├── chat/               ← جریان SSE: مسیریابی، حافظه، پژوهش، بینایی، نگهبان زبان
│       ├── conversations/[id]/ ← CRUD گفتگو + پیام‌ها
│       ├── folders/[id]/       ← CRUD پوشه‌ها
│       ├── memories/[id]/      ← حافظه پایدار
│       ├── vision→(chat)       ← مسیر بینایی داخل /api/chat
│       ├── tts, asr, image-gen, search  ← ابزارهای چندوجهی
│       ├── upload, files/[...] ← آپلود امن + سرو فایل
│       └── stats               ← مشاهده‌پذیری
├── components/xenon/           ← workspace, sidebar, chat-area, message-item,
│                                  composer, memory-panel, settings-dialog, markdown
├── lib/xenon/
│   ├── llm.ts                  ← پوشه SDK (فقط سرور): زبان/بینایی/TTS/ASR/تصویر/جست‌وجو
│   ├── sse.ts                  ← کمکی‌های Server-Sent Events
│   ├── prompts.ts              ← سیاست زبان + پرامپت حالت‌ها
│   ├── language-guard.ts       ← تشخیص CJK، نرمال‌سازی، نگاشت خطا
│   ├── models.ts               ← پروفایل‌های مسیریابی (شفاف)
│   ├── store.ts                ← Zustand (کلاینت)
│   ├── api.ts                  ← لایه fetch کلاینت
│   └── types.ts                ← قراردادهای مشترک
└── prisma/schema.prisma        ← Folder, Conversation, Message, Memory, UsageEvent
```

**جریان یک پیام (حالت پژوهش):**
`Composer → POST /api/chat (SSE) → جست‌وجوی وب → ساخت پرامپت (هویت + سیاست زبان + حافظه + منابع) → جریان GLM → نگهبان زبان → ذخیره در SQLite → done + عنوان خودکار`

## 🛡 امنیت
- کلیدها فقط سمت سرور (SDK)، بدون افشای به کلاینت
- اعتبارسنجی ورودی (سقف طول، نوع فایل، پسوند مجاز)
- محافظت از path traversal در سرو فایل
- پالایش خطاهای درگاه (عدم نمایش متن چینی خام)
- حافظه فقط با اقدام صریح کاربر ساخته/حذف می‌شود

## 🗺 نقشه راه واقعی (بدون وعده الکی)

- **فاز ۱ — پلتفرم (انجام شد):** یکپارچه‌سازی GLM، محصول امن و تست‌شده با سیاست زبان سخت‌گیرانه
- **فاز ۲ — تخصصی‌سازی:** عامل‌های ابزارگیر (اجرای کد سندباکس‌شده)، RAG برداری برای اسناد بزرگ، خواننده صفحات وب در حالت پژوهش
- **فاز ۳ — داده و سنجش:** مجموعه ارزیابی فارسی (دقت، استدلال، توهم، سازگاری زبان) با اجرای خودکار و مقایسه مدل‌ها
- **فاز ۴ — Fine-tuning:** SFT/LoRA روی داده قانونی فارسی؛ اثبات بهبود فقط با آزمون held-out
- **فاز ۵ — پژوهش:** توکن‌گذاری بهتر فارسی، استنتاج کارآمد، بررسی ادامه پیش‌آموزش
- **فاز ۶ — استقلال:** مدل‌های متن‌باز self-hosted (Whisper فارسی برای ASR، LLM باز) برای کاهش وابستگی به درگاه خارجی
